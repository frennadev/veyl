## Anti-patterns
Mostly not AI-looking. Tells: the 3-card stat row on the pool page; engineering lines in success modals (circuit names, proof timings); the same icon for Pools and Create pool; "324% APR" estimate (APY bait per PRODUCT.md). Detector: CLI clean; in-page: dim captions 4.38-4.49:1 on the pool page (#pStats, #volPre, #simBox), tiny text 11-11.5px, wide-shadow popovers and width transitions (style notes), 1.1:1 on portfolio balances is a false positive (gradient), disabled buttons exempt.

## Priority issues
- [P0] One-sided add under "Both tokens" is partly refunded and starts out of range, with no warning (pool/panel tabs.tsx useAdd). Fix: auto-switch side or say "Only 0.61 SOL fits; 0.39 SOL stays private", and warn "starts out of range" before confirming. (harden, clarify)
- [P1] No review before an irreversible private action (#actGo). Fix: a one-screen review with amount, range, fee, where the money ends up. (harden)
- [P1] Add tab is a wall of controls; CTA ~2 screens down on mobile. Fix: default to amount + Tight/Balanced/Wide + button; Shape, Min/Max/Bins, chips, simulator under "More options". (distill, layout)
- [P1] "Fee" means two things: "0.05% fee" vs "Fee now 4.67%". Fix: "Trading fee now (rises when the price moves fast)", one place. (clarify)
- [P1] Protocol jargon in success modals and hints (runAction done bodies, Panel ActionHint). Fix: plain outcome sentence; technical lines under "Technical details". (clarify)
- [P2] Default range 1% wide vs 2.9%/day volatility; no preset selected. Fix: default Balanced, selected, "usually stays in range ~1 day". (onboard)
- [P2] "Withdraw" opens "Send privately" (PortfolioPage, MoneyDialogs). (clarify)
- [P2] Errors don't name the problem ("Your shielded balance has 4.50 SOL."; invalid address not mentioned). (harden)
